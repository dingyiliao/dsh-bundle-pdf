# 索引身份与失效规则

> 状态说明：本文件记录 P0 阶段的设计决策，作为实现参考；当前运行时行为以代码和 [架构文档](./architecture.md) 为准。

状态：P0 草案。索引缓存不得把工作副本 revision 或 Worker 代次误当成正文身份。

## 身份层级

| 身份 | 组成 | 用途 | 是否参与持久索引键 |
| --- | --- | --- | --- |
| `sourceDigest` | 源 PDF 字节 SHA-256 | 外部变更、保存冲突 | 作为保守回退身份 |
| `sourceObservation` | path、mtime、size 等 | 快速发现外部变化 | 否 |
| `pageContentDigest` | 页正文、几何、资源和共享渲染依赖 | OCR/视觉/原生文字复用 | 是 |
| `representationDigest` | 内容表示、分块和编码策略 | embedding 和分块复用 | 是 |
| `engineIdentity` | 引擎 id、生产者版本、配置摘要 | 产物来源 | 是 |
| `extractionSemantics` | 提取 schema、语言和质量规则 | 语义兼容判断 | 是 |
| `hostRevision` | 工作副本当前修订 | 权限、新鲜度、证据签发 | 否 |
| `workerGeneration` | Worker 重启代次 | 运行时句柄有效性 | 否 |

## 复用规则

- 只改高亮、批注、便签或书签：正文 OCR、图像描述、分块和向量继续复用。
- 只改一页正文：失效该页及其共享资源依赖闭包，不自动清空整份文档。
- 修改共享字体、XObject、继承页面属性：失效所有受影响页面。
- 无法可靠计算某页身份：仅该页回退到源字节身份。
- 协议版本变化但产物语义不变：不自动清空缓存。
- 提取规则、语言、模型或配置改变语义：只失效对应生产者的产物。
- 引擎卸载：取消当前实例和在途任务，不删除持久产物；相同身份重新注册后允许复用。

## 必测场景

1. 保存普通批注后不产生新的 OCR/embedding 请求。
2. 修改一页正文只重新处理受影响页。
3. 共享资源变化会使依赖闭包内的页失效。
4. 重启或切换会话后可复用已完成结果。
5. 引擎卸载并重新注册后，不重复处理已验证产物。
6. 旧缓存来源、引擎和提取语义不匹配时明确失败或局部重建。
