# 持久数据迁移矩阵

> 状态说明：本文件记录 P0 阶段的设计决策，作为实现参考；当前运行时行为以代码和 [架构文档](./architecture.md) 为准。

状态：P0 草案。删除旧代码不等于删除旧数据读取能力。

| 数据 | 现有身份/格式 | 目标处理 | 损坏或不兼容 | 验收 |
| --- | --- | --- | --- | --- |
| 草稿和操作日志 | `format: 1`、baseKey、sourceHash | 保留读取，新增版本化迁移器 | 备份原记录并标记恢复失败 | 旧草稿打开、编辑、保存、重开 |
| 保存基线 | sourceHash、renderedHash | 区分源摘要、页面摘要和发布摘要 | 无法确认发布则保留冲突 | 保存中断恢复 |
| 阅读位置 | path/source digest 绑定 | 保留旧位置，源变更时降级到页码 | 清理无效锚点 | 重开后位置合理 |
| 证据引用 | refId/inspectionId | 会话句柄重新签发 | 不跨会话直接复用 | 旧引用明确失效 |
| OCR/视觉/向量索引 | retrieval-v1 SQLite | 按 index identity 迁移 | 不兼容产物局部失效 | 重启复用和失败续跑 |
| 索引设置 | 全局引擎 + 每文档开关 | 保留选择，不静默替换引擎 | 引擎不可用时显示不可用 | 设置迁移回归 |
| 加密授权 | 内存凭据、受保护草稿 | 不落盘密码，按权限重建 | 权限不足时只读 | 加密读写回归 |
| 公开 SDK | `src/contracts` 和包出口 | 保留兼容导出，迁移后删除旧入口 | 主版本升级或明确错误 | npm/package smoke |

## 迁移原则

- 迁移前复制原记录或保留可回滚备份。
- 迁移失败不能静默删除用户草稿或索引。
- 降级不承诺理解新操作；先提示保存或丢弃不兼容草稿。
- 每种格式至少准备一个旧版本 fixture 和一个损坏 fixture。
